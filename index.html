Life OS engine

A private, single-user personal assistant.

The Life OS engine is a personal tool built and run by Mason Lowe for his own use. It reads his own calendar and mail to work out what he has committed to, and surfaces the next thing that needs doing as a single queue of cards.

It is not a public service

There is one user, and no sign-up. Nobody else's data is ever read, and there is no way for another person to connect an account to it. It is published here only because Google requires an OAuth application to have a public home page and privacy policy.

What it connects to

  • Google Calendar — read-only
  • Gmail — read-only, message headers and labels rather than message bodies
  • GitHub and Claude Code, for a record of what was worked on
